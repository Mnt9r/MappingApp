# MappingApp — CIA 3003 MapKit Assignment

SwiftUI + MapKit iOS application for UAE landmarks, location services, map controls, map styles and place search with MKLocalSearch.

## Features
- Markers for Dubai Mall, Burj Khalifa and Sheikh Zayed Grand Mosque
- Custom Louvre Abu Dhabi annotation
- User location with permission request
- Pan, zoom, rotate and pitch controls
- Standard/hybrid map styles, compass and location button
- Search bar that centers the map on matching places

## Run
Open MappingApp.xcodeproj in Xcode 15+ on macOS, select an iOS 17+ simulator or device, and press Run. Map data and search require internet access.
